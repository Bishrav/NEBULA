# NEBULA v0.1.0 - Research Prototype

NEBULA is a Java 17 search prototype for studying explainable hybrid retrieval and trust-oriented ranking signals.

## Included in this release

- BM25 lexical retrieval, BGE-backed semantic retrieval, hybrid ranking, HNSW indexing, and PageRank-based trust signals.
- An attributed public corpus of 843 documents with provenance records.
- Reproducible evaluation and validation tooling, including blinded pooled annotation workflows.
- Protected labels and split metadata for a fresh held-out known-item/source-page evaluation.
- Research documentation, claim controls, agreement analysis, and local/CI verification guidance.

## Current evidence boundary

The current evaluation covers 308 judged pairs across 16 queries. It is preliminary pooled known-item/source-page evidence, not a validated claim about corpus-wide relevance, user benefit, statistical superiority, or production-scale search. Trust-signal ablation results remain limited and should not be presented as a completed general conclusion.
