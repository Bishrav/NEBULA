# Post-task and post-session questionnaire

**DRAFT — REQUIRES INSTITUTIONAL/SUPERVISOR REVIEW**

Use only the questions approved by the institution. Do not collect unnecessary demographic or employment information.

## After each task

1. How confident are you that the selected source addresses the task? (1 = not confident, 5 = very confident)
2. What evidence influenced your decision? (optional, avoid private information)
3. Was anything confusing or difficult? (optional)

## After each condition

1. How easy was it to find a useful source? (1–5)
2. How easy was it to verify the source? (1–5)
3. Which information on the result page did you use? (select approved options)
4. Did any signal make you trust a result more or less? Explain without naming a private source.

## End of session

1. Which interface was easier to use, and why?
2. Which interface made verification easier, and why?
3. Did any explanation feel misleading, incomplete, or distracting?
4. Did the study environment cause discomfort or concern?
5. Is there anything you want removed before analysis? Follow the approved withdrawal process rather than collecting identifying details here.
