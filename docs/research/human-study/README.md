# NEBULA human-study submission package

**DRAFT — REQUIRES INSTITUTIONAL/SUPERVISOR REVIEW**

This directory contains preparation materials for a possible future human evaluation of NEBULA. It is not ethics approval, an exemption determination, participant recruitment, or evidence from human participants.

## Proposed study

The study would compare conventional hybrid retrieval with NEBULA's trust/evidence-oriented presentation for engineering-documentation tasks. The primary purpose is to measure task success and verification behavior, not to evaluate participant expertise.

## Absolute boundaries

- No participant recruitment may begin from this repository.
- No human data may be generated, committed, or described as collected.
- Institution-specific approval fields remain blank until supplied by an authorized reviewer.
- The study must use the approved consent language, approved storage location, and approved retention period.
- If the institution determines that review is not required, preserve that written determination with the study record.
