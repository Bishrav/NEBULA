# Ethics and human-study submission checklist

**DRAFT — REQUIRES INSTITUTIONAL/SUPERVISOR REVIEW**

## Institutional decisions

- [ ] Supervisor identified.
- [ ] Institution and responsible review body identified.
- [ ] Review/approval or exemption determination received in writing.
- [ ] Data-protection/privacy determination received.
- [ ] Participant age and vulnerability requirements confirmed.
- [ ] Compensation and recruitment rules confirmed.

## Documents

- [ ] Protocol reviewed and versioned.
- [ ] Participant information sheet approved.
- [ ] Consent form approved.
- [ ] Recruitment text approved.
- [ ] Task script and success rubric frozen.
- [ ] Questionnaire approved.
- [ ] Debriefing sheet approved.
- [ ] Risk assessment accepted.
- [ ] Data-management plan accepted.
- [ ] Analysis plan preregistered or otherwise frozen.

## Technical controls

- [ ] Fresh telemetry file created for each wave.
- [ ] Consent gate verified before persistence.
- [ ] Anonymous session identifiers tested.
- [ ] No private-source ingestion enabled.
- [ ] Raw-data storage access tested.
- [ ] Withdrawal/deletion procedure tested.
- [ ] Export redaction and validation pass.
- [ ] No participant data present in Git, CI, logs, or public artifacts.

## Release gate

- [ ] Human study status updated only by the responsible researcher after review.
- [ ] Claim ledger updated from actual evidence only.
- [ ] Any public derivative receives privacy and licensing review.

Until every required item is resolved, status remains **HUMAN STUDY PENDING**.
